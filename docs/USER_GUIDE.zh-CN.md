## 真实例子：一家医院想建立内部医学知识库

假设有一家医院，拥有一本 600 页的《急诊医学手册》（PDF 格式）。他们希望让医生能够通过 AI 聊天界面快速查询，而不需要每次都翻书。

医院的 IT 主管决定使用 DocOracle。以下是他们每一步的操作，以及看到的画面。

---

## 第一步：先试用在线演示（无需安装）

在安装任何东西之前，IT 主管先前往 DocOracle 在线演示：**[decca-oracle.manus.space](https://decca-oracle.manus.space)**。

首页提供两个选项：

- **「探索演示」** — 加载预先处理好的示例文件，让你立即看到知识库的样子，无需上传任何东西。
- **「用你的 PDF 试试」** — 让你上传自己的 PDF，并对其执行完整的 pipeline。

IT 主管点击 **「用你的 PDF 试试」**，上传了手册的 50 页节选，然后等待。

---

## 第二步：上传与 Pipeline 处理画面

上传后，用户会进入 **最近上传** 画面。这个画面显示所有已提交的 PDF 及其当前处理状态。

列表中的每个项目显示：

| 列 | 说明 |
|----|------|
| **文件名** | 已上传 PDF 的名称 |
| **状态标签** | 其中之一：`排队中`、`处理中`、`已完成`、`失败` |
| **「查看进度」按钮** | 打开该上传的任务详情页面 |
| **垃圾桶图标按钮** | 立即删除该任务（适用于所有状态） |

> **在线演示的真实例子：** 上传 *Emergency_Medicine_Excerpt.pdf* 后，最近上传列表显示：
>
> ```
> Emergency_Medicine_Excerpt.pdf   [处理中]   [查看进度]  [🗑]
> ```

垃圾桶图标（🗑）出现在「查看进度」按钮的**左侧**。你可以随时删除任何任务——包括仍在排队或正在处理中的任务——以防止它们继续消耗 API 额度。

---

点击 **「查看进度」** 会打开任务详情页面。在 pipeline 执行期间，你会看到实时进度指示器，显示目前正在执行 12 个步骤中的哪一个：

## 第四步：Pipeline 失败时的处理方式

有时 pipeline 会失败——例如 Gemini API 达到速率限制，或 PDF 包含异常编码。发生这种情况时，任务详情页面会显示清晰的 **「Pipeline 失败」** 错误卡片。

卡片上并排显示两个按钮：

- **「再试一次」** — 重新排队该任务，从头开始尝试 pipeline。
- **「删除」** — 永久从系统中移除该任务。

> **为什么「删除」按钮很重要：** 如果任务反复失败，一直点击「再试一次」会不断消耗 API 额度而没有任何结果。「删除」按钮让你干净地移除失败的任务，防止它在后台继续重试。

**真实例子：** IT 主管不小心上传了一个损坏的 PDF。Pipeline 在步骤 2 失败。他没有点击「再试一次」（那样会再次失败），而是点击了 **「删除」**，然后重新上传正确的文件。

## 第五步：知识库中心 — Pipeline 完成后看到的画面

这是本指南最重要的部分。一旦 pipeline 成功完成，任务详情页面就会转变为 **知识库中心（Knowledge Hub）** — 一个包含三个选项卡的完整界面。

### 统计栏

知识库中心顶部的统计栏显示已提取内容的快速摘要：

```
📄 50 页   |   🖼 12 个视觉资产   |   📑 8 个章节   |   📖 23 个词汇
```

### 选项卡一：书籍结构

**书籍结构**选项卡显示文件的完整章节和段落层次结构。每个条目显示：

- 章节标题和页码范围（例如「第三章：胸痛评估 — 第 42–67 页」）
- 该章节内容的一段摘要
- 关键主题标签（例如 `心电图`、`肌钙蛋白`、`鉴别诊断`）

**点击任何章节**会打开一个关于该章节的预填聊天问题。例如，点击「第三章：胸痛评估」会自动询问：*「第三章关于胸痛评估涵盖了什么内容？」*

> **在线演示的真实例子：** IT 主管浏览到「第五章：创伤处理方案」并点击它。AI 立即以结构化摘要回答，引用了手册中的具体页面。

### 选项卡二：词汇表

**词汇表**选项卡显示从文件中提取的每个技术术语，以可搜索的卡片形式呈现。每张卡片显示：

- 术语（例如「肌钙蛋白 I」）
- 从文件中提取的定义
- 出现的页码
- 类别标签（例如 `生物标志物`、`诊断`）

词汇表选项卡顶部有一个**搜索栏**。输入「心电图」会过滤列表，只显示与心电图相关的术语。

**点击任何词汇卡片**会打开一个预填聊天问题。例如，点击「肌钙蛋白 I」会询问：*「你能更详细地解释肌钙蛋白 I 吗？」*

> **在线演示的真实例子：** 一位医生使用词汇表选项卡查找「STEMI」（ST 段抬高型心肌梗死）。卡片显示了定义、页码范围（第 246–251 页）和 `心脏病学` 标签。点击卡片后打开了一个要求更多详情的聊天，AI 回应了引用第 246、248 和 250 页的完整解释。

### 选项卡三：开始提问

**开始提问**选项卡显示从文件内容生成的 6 个建议问题。这些问题旨在帮助新用户了解 DocOracle 能回答哪些类型的问题。

急诊医学手册的建议问题示例：

1. 「过敏反应的一线治疗是什么？」
2. 「如何评估意识状态改变的患者？」
3. 「疑似肺栓塞建议做哪些影像学检查？」
4. 「启动创伤团队的标准是什么？」
5. 「如何解读 12 导联心电图的 STEMI？」
6. 「妊娠紧急情况中哪些药物是禁忌？」

点击任何建议问题会直接将其发送到 AI 聊天。

## 第六步：使用 AI 聊天

探索知识库中心选项卡后，医生点击其中一个建议问题或自行输入。AI 回应包含：

1. 以文件为依据的结构化答案
2. 精确的页码引用
3. 答案旁边自动显示相关图表或表格

**真实对话例子：**

> **医生：**「如果患者有严重胸痛，我应该做哪些检查？」
>
> **DocOracle AI：**「根据手册（第 245–250 页），对于严重胸痛的患者，建议进行以下检查：
>
> 1. **心电图（ECG）** — 到达后 10 分钟内进行。解读指南见第 246 页。
> 2. **胸部 X 光** — 排除气胸和主动脉夹层。见第 248 页。
> 3. **血液检查** — 肌钙蛋白 I、BNP、D-二聚体。参考值见第 250 页。
>
> [图表：心电图解读流程图 — 从第 247 页提取]
>
> [按钮：**转换为图片说明** — 点击生成此答案的视觉摘要]」

**「转换为图片说明」**按钮会生成一个 AI 创建的视觉图表，总结答案——适合快速参考或教学使用。

## 第七步：管理你的上传

### 从最近上传列表删除任务

在 DocOracle 主页面，**最近上传**部分列出了你所有已处理的文件。每一行在「查看进度」按钮左侧都有一个垃圾桶图标（🗑）按钮。

你可以删除**任何状态的任务**：

| 状态 | 可以删除？ | 效果 |
|------|-----------|------|
| `排队中` | 是 | 在开始前取消任务 |
| `处理中` | 是 | 中途停止 pipeline |
| `已完成` | 是 | 永久移除知识库 |
| `失败` | 是 | 清理失败的任务 |

> **为什么这很重要：** 未删除的失败任务可能会自动重试，消耗 API 额度。立即删除它们可以阻止这种情况。

### 从任务详情页面删除任务

当你正在查看特定任务（无论成功还是失败）时，该页面上也有一个**删除**按钮：

- 在**已完成**的任务上：删除按钮出现在知识库中心标题栏，文件标题旁边。
- 在**失败**的任务上：删除按钮出现在错误卡片内「再试一次」按钮旁边。

## 第八步：部署你自己的实例（开发者路径）

如果你想在自己的服务器上使用自己的文件运行 DocOracle，请按照以下步骤操作。

### 先决条件

| 需求 | 版本 | 用途 |
|------|------|------|
| Python | 3.9+ | Pipeline 脚本 |
| Node.js | 18+ | 网站 |
| pdftotext | 任意 | 文字提取（`sudo apt-get install poppler-utils`） |
| Gemini API 密钥 | — | Vision 分析和聊天（[获取免费密钥](https://aistudio.google.com/app/apikey)） |

### 逐步说明

**1. 克隆仓库**

```bash
git clone https://github.com/dev-james0723/DocOracle.git
cd DocOracle
```

**2. 将你的 PDF 放入 `input/` 文件夹**

```bash
cp /path/to/your/handbook.pdf input/
```

**3. 安装 pipeline 依赖项**

```bash
pip install -r pipeline/requirements.txt
```

**4. 设置你的 Gemini API 密钥**

```bash
export GEMINI_API_KEY="your-gemini-api-key"
```

**5. 运行 pipeline**

```bash
bash pipeline/run_all.sh
```

**6. 将输出文件复制到网站**

```bash
cp output/05_retrieval/page_chunks.jsonl website/server/data/
cp output/04_gold_master/glossary.json website/server/data/
cp output/04_gold_master/sections.json website/server/data/
cp output/10_visual_assets/visual_assets_index.json website/server/data/visual_assets.json
```

**7. 启动网站**

```bash
cd website
npm install
npm run dev
```

在浏览器中打开 `http://localhost:3000`。你的 AI 知识库已准备就绪。

## 常见问题

**问：Pipeline 需要多长时间？**
答：50 页文件约 15 分钟，200 页约 1 小时，500 页约 3 小时。处理时间取决于视觉资产（图表、表格）的数量，因为每个都由 Gemini Vision 单独分析。

**问：需要付费使用 Gemini API 吗？**
答：Gemini 有免费方案，涵盖小型文件（最多约 50 页）。对于较大的文件，你可能需要付费 API 密钥。请查看 [Google AI Studio](https://aistudio.google.com) 了解当前定价。

**问：可以使用 Gemini 以外的 LLM 吗？**
答：可以。编辑 `pipeline/config.yaml` 指向不同的模型端点。Pipeline 的文字步骤设计为模型无关；只有 Vision 分析步骤需要多模态模型。

**问：如果 Pipeline 中途失败怎么办？**
答：Pipeline 在每个步骤都会保存进度。如果在步骤 7 失败，你可以从步骤 7 重新执行，而不需要重复步骤 1–6。或者，从界面删除任务并重新开始。

**问：可以删除已完成的知识库吗？**
答：可以。使用最近上传列表中的垃圾桶图标，或任务详情页面上的删除按钮。这会永久移除任务及所有相关数据。

**问：支持哪些文件格式？**
答：目前仅支持 PDF。计划在未来版本中支持 DOCX、EPUB 和 HTML。

## 总结：用户获得的功能

对文件执行 DocOracle 后，用户可以使用：

| 功能 | 描述 |
|------|------|
| **附引用的 AI 聊天** | 提问，获得附精确页码的答案 |
| **书籍结构选项卡** | 浏览章节和段落；点击任何一个即可提问 |
| **词汇表选项卡** | 搜索所有提取的术语；点击任何一个即可要求更多详情 |
| **开始提问选项卡** | 从文件生成的 6 个建议问题 |
| **视觉资产检索** | 相关图表自动出现在答案旁边 |
| **图片说明** | 为任何复杂答案生成视觉摘要 |
| **删除控制** | 随时移除任何任务（排队中、处理中、已完成或失败） |
