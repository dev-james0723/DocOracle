# DocOracle Website

This is the full-stack web application that serves the AI knowledge base generated by the DocOracle pipeline.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React 19 + TypeScript + Tailwind CSS 4 |
| Backend | Express 4 + tRPC 11 |
| Database | MySQL (via Drizzle ORM) |
| LLM | Gemini (via invokeLLM helper) |
| Image Generation | AI image generation (via generateImage helper) |

## Setup

### 1. Copy Pipeline Output

After running the DocOracle pipeline, copy the 4 key files into `server/data/`:

```bash
cp output/05_retrieval/page_chunks.jsonl website/server/data/
cp output/04_gold_master/glossary.json website/server/data/
cp output/04_gold_master/sections.json website/server/data/
cp output/10_visual_assets/visual_assets_index.json website/server/data/visual_assets.json
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm run dev
```

The website will be available at `http://localhost:3000`.

## Pages

| Page | Route | Description |
|------|-------|-------------|
| Home | `/` | Landing page with navigation and suggested prompts |
| Chat | `/chat` | AI chat interface with citations and diagram retrieval |
| Glossary | `/glossary` | Alphabetical glossary browser with category badges |
| Sections | `/sections` | Book structure navigator with summaries |
| DocOracle | `/doc-oracle` | PDF upload demo page |

## Key Files

```
server/
  knowledgeBase.ts    — Knowledge base loader and search engine
  routers.ts          — tRPC API routes (chat, search, glossary, sections)
  pipeline.ts         — Background pipeline for uploaded PDFs
  data/               — Place your pipeline output files here

client/src/pages/
  Home.tsx            — Landing page
  Chat.tsx            — AI chat interface
  Glossary.tsx        — Glossary browser
  Sections.tsx        — Section navigator
  DocOracle.tsx       — PDF upload page
  DocOracleJob.tsx    — Per-job pipeline progress and chat
```
